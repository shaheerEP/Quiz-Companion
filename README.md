# 3D Tajweed Studio

Standalone Next.js application for the interactive **3D Tajweed Studio (مخارج الحروف وصفاتها)** extracted from the `/tajweed` page.

## Features

- Interactive 3D oral/throat anatomy articulation viewer powered by Three.js
- Full Arabic letter Makharij presets and Sifaat al-Huroof reference
- Native Arabic letter audio pronunciations (`/public/audio/letters/`)
- Multilingual interface (English, العربية, മലയാളം) with light/dark/system theme toggle

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (requests to `/tajweed` also redirect to `/`).

## Build

```bash
npm run build
npm run start
```
